🎵 Bytebeat Desktop Mini — Compact 8-bit Music Studio for Windows 10/11

A lightweight standalone desktop wrapper for Dollchan Bytebeat Composer. No installation, no bloat — just pure algorithmic chiptune in a clean mini-window.

✨ Features:
• Zero dependencies: Single tiny .bat script (~1.5 KB), runs out of the box via built-in Microsoft Edge.
• Distraction-free window: Fixed 460×580 app window with Minimize & Close buttons only (no tabs or address bar).
• Instant workspace: Opens directly in 8000 Hz Bytebeat mode with live oscilloscope and a starter formula ready to play.
• Clean session: Uses an isolated temporary profile so your main browser stays untouched.

🚀 How to run:
1. Download and extract bytebeatmini.zip using the link below.
2. Double-click Bytebeat.bat to launch.
(If Windows SmartScreen pops up on first launch, click "More info" → "Run anyway").
